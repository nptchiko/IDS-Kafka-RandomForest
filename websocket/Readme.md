### This is module create socket 

This module use socket io to create socket with UI
Run this here after mongodb and before UI

## Run command
___Navigate here___

Make sure install all library in requirement
Or run command here

```
pip install -r requirement.txt
```

```
python3 server.py
```

## Server running:

Server runs with port 5000.

With 4 collections of data: __tls_pie_data__, __status_info__, __missed_bytes_data__, __missed_bytes_data__. Each collection stand for one information that socket server sent to UI.
